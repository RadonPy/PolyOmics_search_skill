# Public simulation search

- Use live tool names and argument schemas, including any wrapper such as `request`. Discovery calls accept a narrower field category or query when exposed. Read `get_dataset_info` for source revision and provenance, and call `list_search_fields` only for the schema needed. Resolve stable IDs and use returned units; distinguish class flags, quality flags, text, and numeric properties. Convert user units only when definitions and conversion are clear.
- For constraints, use `search_polymers` with bounded `limit`, specific output fields, discovered numeric ranges, class flags and `class_logic`. Request a reproducible sort on the named property and direction. For SMARTS/SMILES use the structure input and report that matching is against `search_smiles` if that is the deployed searchable field. Explain chirality choices and invalid-target or timeout warnings. Avoid a broader chemistry search than the question requires.
- Only apply `check_eq`, `check_tc` or other quality flags for a stated reason relevant to the task. Report flags applied, missing property values, sample sizes and the duplicate policy. A UUID identifies a simulation record; the same structure may have several runs. Use a server-defined structure key if exposed, otherwise do not imply deduplication by UUID removes duplicate structures. Preserve distinguishable runs when comparing replicate behavior.
- Use `get_polymer` with a reported UUID and the subset of public fields needed. Use `aggregate_polymers` for the complete filtered MD cohort, not statistics computed on the visible search page. Report valid-value count versus total, grouping and null treatment as applicable. Keep cursor, filters, sort, and revision consistent between pages; restart or explain if a cursor becomes stale. A zero-match result differs from an empty catalog, invalid query, or outage.

# Experimental and application workflow

1. For experimental or application tasks, resolve target properties and operating conditions. For a thermally conductive insulating film, consider thermal conductivity in the relevant direction, electrical conductivity or resistivity, dielectric breakdown strength when relevant, and the service temperature relative to Tg. Permittivity and dielectric loss characterize response to an electric field and leave the insulation constraint unresolved on their own. Identify which constraints are required. Simulation-only requests follow the MD workflow and can omit Evidence.
2. Use `get_dataset_info` and `list_search_fields` for current MD definitions, units, quality flags and revision. Use `get_sim2real_catalog` with a property query and `include_metric_definitions` for canonical IDs, aliases, role-specific coverage, permitted use and release metadata. An absent tool, blocked call, unsupported property, tool error, and a successful empty result each require a different explanation.
3. Use bounded `search_sim2real_evidence` queries by canonical target and relevant source. For Indirect, `md_property_id` selects the predicted Source MD property and `experimental_property_id` the measured target. Check strong associations of either sign. Use absolute-value sorts or confirmed separate positive/negative queries where supported. Check returned sort metadata and page completeness before claiming an ordering. Keep filters and sort fixed when following `next_cursor`. Stop on null, repeated cursors, or changed release.
4. Fetch shortlisted `get_sim2real_evidence` records at the returned `evidence_revision`. Fetch member and independent Source validation by their separate IDs where relevant. Keep Catalog, Search, Detail and validation within one Evidence release. Record the searched MD revision, Evidence revision and original source MD revision separately. Preserve `not_recorded` as unknown.
5. Retrieve bounded MD candidate records or a legitimately available exact predictor for each target. Verify axes, definitions, conditions and authorization, then choose an estimate, proxy, hypothesis or explicit gap. Where an eligible fit guides selection, apply it to the relevant predictor and retain the user's other constraints. For an uncomputed target, use relevant Indirect Evidence and corroborating chemistry to identify candidate screening variables. [Evidence interpretation](evidence-interpretation.md)
